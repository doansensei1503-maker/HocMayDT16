# Tài liệu trình chiếu
presentation.tex là nguồn Beamer với kết quả thực nghiệm thật cấu hình seed42/max_rows6000. Chưa biên dịch PDF vì không có XeLaTeX. Không phải template slide chính thức.
Khi có compiler: vào slides, chạy xelatex presentation.tex hai lần. Cần tự bổ sung tên nhóm và chuẩn bị trả lời các câu hỏi trong outline.md. Nếu đổi cấu hình thực nghiệm phải cập nhật số liệu phần chữ, bảng/hình vẫn đọc từ results.
