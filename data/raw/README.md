# Nguồn dữ liệu
Link người dùng cung cấp thiếu hậu tố -analysis. Link thật trích từ annotation PDF FIT4013:
https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis
Tải và giải nén DataCoSupplyChainDataset.csv và DescriptionDataCoSupplyChain.csv vào đây. Không dùng nguồn thay thế hoặc dữ liệu tổng hợp để báo cáo metric.
Nếu API công khai không tải được, đăng nhập Kaggle và tải thủ công từ link trên. Không lưu token trong repository. Phải kiểm tra tên file sau giải nén; runner kiểm tra schema và target trước huấn luyện. Encoding thử UTF-8 rồi CP1252, ghi vào manifest. SHA256 được tính từ bytes thật mỗi lần chạy.
Nguồn gốc để tham khảo, không tự động thay nguồn Kaggle: Constante, Silva, Pereira (2019), DataCo SMART SUPPLY CHAIN FOR BIG DATA ANALYSIS, Mendeley Data V5, DOI 10.17632/8gx2fvg2k6.5. Giấy phép nguồn gốc CC BY 4.0; cần đối chiếu điều kiện trên Kaggle trước phân phối lại.
